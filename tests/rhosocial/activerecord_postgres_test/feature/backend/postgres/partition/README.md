# partition tests

PostgreSQL declarative partitioning: partition operations (incl. pg_partman and production-style time partitioning), advanced partition capabilities and EXPLAIN on partitioned tables.

## Key files

- `test_partition_advanced_operations.py` — advanced partition capabilities
- `test_partition_explain.py` — EXPLAIN on partitioned tables
- `test_partition_operations.py` — partition operations incl. pg_partman
