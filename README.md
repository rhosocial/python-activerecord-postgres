It cannot be used standalone.

## Quick Start

```python
from typing import ClassVar, Optional
from uuid import UUID, uuid4

from rhosocial.activerecord.base import FieldProxy
from rhosocial.activerecord.backend.impl.postgres.backend import PostgresBackend
from rhosocial.activerecord.backend.impl.postgres.config import PostgresConnectionConfig
from rhosocial.activerecord.backend.expression import CreateTableExpression
from rhosocial.activerecord.backend.expression.statements import (
    ColumnConstraint,
    ColumnConstraintType,
    ColumnDefinition,
)
from rhosocial.activerecord.backend.expression.types import (
    ArrayType,
    JsonBType,
    TextType,
    UUIDType,
    VarCharType,
)
from rhosocial.activerecord.model import ActiveRecord


class Article(ActiveRecord):
    __table_name__ = "articles"

    id: Optional[UUID] = None
    title: str
    tags: list[str]              # maps to text[] / TEXT[]
    metadata: dict               # maps to JSONB

    c: ClassVar[FieldProxy] = FieldProxy()


Article.configure(
    PostgresConnectionConfig(
        host="localhost",
        port=5432,
        database="myapp",
        username="user",
        password="password",
    ),
    PostgresBackend,
)

dialect = Article.__backend__.dialect
Article.__backend__.execute(*CreateTableExpression(
    dialect,
    "articles",
    columns=[
        ColumnDefinition(
            dialect, "id", UUIDType(dialect),
            constraints=[ColumnConstraint(dialect, ColumnConstraintType.PRIMARY_KEY)],
        ),
        ColumnDefinition(dialect, "title", VarCharType(dialect, 200)),
        ColumnDefinition(dialect, "tags", ArrayType(dialect, TextType(dialect))),
        ColumnDefinition(dialect, "metadata", JsonBType(dialect)),
    ],
).to_sql())
# CREATE TABLE "articles" ("id" UUID PRIMARY KEY, "title" VARCHAR(200),
#   "tags" TEXT[], "metadata" JSONB)
```

> Type mapping is not automatic for every field. `list[str]` and `dict` need
> either an explicit `DataType` in the DDL above or a type adapter; check
> [type adapters](docs/en_US/type_adapters/) before assuming the column
> matches your annotation.

### Async

`AsyncPostgresBackend` exposes the same API. Method names are identical; add
`await`.

```python
from rhosocial.activerecord.backend.impl.postgres.backend import AsyncPostgresBackend
from rhosocial.activerecord.model import AsyncActiveRecord


class Article(AsyncActiveRecord):
    ...


Article.configure(config, AsyncPostgresBackend)
rows = await Article.query().where(Article.c.title == "hello").all()
```

## PostgreSQL-Specific Features

### Native arrays

No serialization adapter is needed for `text[]`; operators map straight
through.

```python
Article.query().where("tags @> ARRAY[?]", ("python",)).all()
Article.query().where("? = ANY(tags)", ("python",)).all()
Article.query().where("tags && ARRAY[?]", ("python",)).all()
```

### JSONB

```python
Product.query().where("metadata->>'brand' = ?", ("Dell",)).all()
Product.query().where("metadata @> ?", ('{"brand": "Dell"}',)).all()
```

## Known Limitations

- **No connection pooling by default.** This backend connects on use and
  keeps a single connection. Optional pooling is a separate extra:
  `pip install rhosocial-activerecord-postgres[pooling]`, configured with
  `pool_min_size` / `pool_max_size` / `pool_timeout`. See
  [connection management](docs/en_US/installation_and_configuration/pool.md).
- **`RETURNING` is version-gated.** The basic clause works broadly, but
  `returning_old_new` and `update_returning_old` need PostgreSQL 18.
- Field annotations do not drive DDL. `list[str]`, `dict` and `UUID` columns
  are described explicitly in the `CreateTableExpression` above.

## Testing

Tests require a reachable PostgreSQL server and must run serially.

```bash
export PYTHONPATH=src:tests
.venv3.14-ubuntu26.04/bin/pytest tests/
```

The shared contract suite lives in
[python-activerecord-testsuite](https://github.com/rhosocial/python-activerecord-testsuite):

```bash
PYTHONPATH=tests .venv3.14-ubuntu26.04/bin/pytest \
  ../python-activerecord-testsuite/src/rhosocial/activerecord/testsuite/feature/
```
