Fixed the unused-indexes listing: `indisvalid` is now read from `pg_index` (joined on `indexrelid`) instead of `pg_stat_user_indexes`, which carries only scan counters. Naming that column on the statistics view made the server reject the whole statement (`column i.indisvalid does not exist`), so `list_unused_indexes()` and `introspect unused-indexes` could not answer on any real PostgreSQL server.
